# HƯỚNG DẪN CHẠY LiMS

## 1. ĐIỀU KIỆN

- Cài đặt .NET SDK 10.
- Cài đặt và khởi động Microsoft SQL Server.
- Có database `LiMSDB`.
- Cấu hình chuỗi kết nối phù hợp với SQL Server trên máy cá nhân.
- Sử dụng PowerShell tại thư mục gốc dự án.

API sử dụng Entity Framework Core để kết nối và thao tác với SQL Server. Admin và Website giao tiếp với API, không kết nối trực tiếp đến database.

## 2. CẤU HÌNH MÔI TRƯỜNG

### 2.1. Cấu hình chuỗi kết nối

Không nên sửa chuỗi kết nối dùng chung trong `appsettings.json` để phù hợp với từng máy cá nhân.

Mở PowerShell tại thư mục gốc dự án và chạy:

```powershell
dotnet user-secrets set "ConnectionStrings:LiMS" "Server=localhost\SQLEXPRESS;Database=LiMSDB;Trusted_Connection=True;TrustServerCertificate=True;Encrypt=True" --project .\LiMS.Api\LiMS.Api.csproj
```

Thay `SQLEXPRESS` bằng tên SQL Server instance đang sử dụng trên máy.

Ví dụ:
- `localhost\SQLEXPRESS`
- `localhost\MARKUS`

### 2.2. Cấu hình JWT Signing Key

API cần khóa ký JWT ổn định để xác thực token giữa các lần khởi động.

Tạo khóa ngẫu nhiên và lưu bằng User Secrets:

```powershell
$key = [Convert]::ToBase64String(
    [System.Security.Cryptography.RandomNumberGenerator]::GetBytes(64)
)

dotnet user-secrets set "Jwt:SigningKey" $key --project .\LiMS.Api\LiMS.Api.csproj

$key = $null
```

Không đưa khóa JWT lên GitHub hoặc chia sẻ khóa bí mật giữa các máy.

### 2.3. Cấu hình tài khoản quản trị ban đầu

API hỗ trợ tự động tạo tài khoản quản trị đầu tiên khi khởi động nếu chưa tồn tại tài khoản Admin.

Cấu hình bằng User Secrets:

```powershell
dotnet user-secrets set "BootstrapAdmin:Username" "admin" --project .\LiMS.Api\LiMS.Api.csproj
dotnet user-secrets set "BootstrapAdmin:Password" "THAY_BANG_MAT_KHAU_RIENG" --project .\LiMS.Api\LiMS.Api.csproj
dotnet user-secrets set "BootstrapAdmin:Email" "admin@library.local" --project .\LiMS.Api\LiMS.Api.csproj
dotnet user-secrets set "BootstrapAdmin:FullName" "Library Administrator" --project .\LiMS.Api\LiMS.Api.csproj
dotnet user-secrets set "BootstrapAdmin:StaffCode" "ADM-001" --project .\LiMS.Api\LiMS.Api.csproj
```

Thay mật khẩu mẫu bằng mật khẩu riêng của từng người phát triển. Không chia sẻ mật khẩu hoặc đưa thông tin bí mật lên GitHub.

Nếu database đã có tài khoản Admin với username được cấu hình, API sẽ không tạo lại hoặc ghi đè tài khoản đó.

### 2.4. Kiểm tra cấu hình

API sử dụng User Secrets trong môi trường Development để đọc các cấu hình cá nhân.

Có thể kiểm tra cấu hình bằng cách khởi động API và theo dõi log kết nối database, migration và quá trình khởi tạo tài khoản quản trị.

Không chia sẻ nội dung User Secrets vì có thể chứa mật khẩu và khóa bí mật.

## 3. CHẠY CHƯƠNG TRÌNH ADMIN

Tại thư mục gốc dự án, chạy:

```powershell
.\start-admin.bat
```

Launcher sẽ kiểm tra và khởi động API tại:

`http://localhost:5107`

Sau đó mở ứng dụng Admin.

Tài khoản quản trị:
- Tên tài khoản: `admin`
- Mật khẩu: mật khẩu quản trị đã được thiết lập trong môi trường tương ứng.

Không lưu mật khẩu trong tài liệu hoặc đưa lên GitHub.

## 4. CHẠY WEBSITE CHO ĐỘC GIẢ

Tại thư mục gốc dự án, chạy:

```powershell
.\start-frontend.bat
```

Launcher sẽ kiểm tra và khởi động API nếu cần, sau đó chạy Website và mở trình duyệt.

- Website: `http://localhost:5500`
- API: `http://localhost:5107`

Tài khoản độc giả không được tạo sẵn. Đăng nhập Admin, mở mục Độc giả, chọn Thêm độc giả để tạo tài khoản và mật khẩu ban đầu cho người dùng Website.

Người dùng Website đăng nhập bằng tài khoản độc giả vừa được tạo.

## 5. CHẠY CẢ ADMIN VÀ WEBSITE

Có thể chạy cả `start-admin.bat` và `start-frontend.bat`.

Hai ứng dụng sử dụng chung API tại cổng 5107 và cùng database `LiMSDB`. Không cần khởi động hai API riêng biệt.

## 6. CHẠY THỦ CÔNG NẾU FILE BAT KHÔNG HOẠT ĐỘNG

Mở hai cửa sổ PowerShell tại thư mục gốc dự án.

Cửa sổ 1 - Khởi động API:

```powershell
dotnet run --project .\LiMS.Api\LiMS.Api.csproj --launch-profile http
```

Giữ cửa sổ API mở trong lúc sử dụng chương trình.

Cửa sổ 2 - Chạy Admin:

```powershell
dotnet run --project .\LiMS.Admin\LiMS.Admin.csproj
```

Hoặc chạy Website:

```powershell
dotnet run --project .\LiMS.Web\LiMS.Web.csproj --urls http://localhost:5500
```

## 7. KIỂM TRA API VÀ DATABASE

Mở trình duyệt:

`http://localhost:5107/api/library/health`

Kết quả mong đợi:

```json
{
  "status": "ok",
  "database": true
}
```

Nếu xảy ra lỗi kết nối SQL Server:
- Kiểm tra dịch vụ SQL Server đang chạy.
- Kiểm tra tên instance.
- Kiểm tra database `LiMSDB` đã tồn tại.
- Kiểm tra cấu hình `ConnectionStrings:LiMS` trong User Secrets.

API có thể thực hiện cập nhật migration khi khởi động. Cần bảo đảm cấu hình kết nối đang trỏ đúng database trước khi chạy API.

## 8. LƯU Ý BẢO MẬT

- Không đưa mật khẩu Admin, JWT Signing Key hoặc dữ liệu cá nhân thật lên GitHub.
- Không lưu cấu hình cá nhân trong `appsettings.json`.
- Không đưa thư mục `bin/`, `obj/` và các tệp cấu hình cá nhân lên kho mã nguồn.
- Mỗi máy phát triển cần tự cấu hình User Secrets.
